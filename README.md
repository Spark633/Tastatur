# Tastatur

Eigene Android-Tastatur, angepasst an meine Wünsche.

## Installieren

1. Unter **Releases → Neueste Version** die Datei `Tastatur.apk` auf dem Handy herunterladen.
2. Öffnen und installieren (beim ersten Mal „Unbekannte Apps installieren“ für den Browser bzw. Dateimanager erlauben).
3. App **Tastatur** öffnen → Schritt 1 (aktivieren) und Schritt 2 (auswählen).

Jeder Push auf `main` baut automatisch eine neue APK. Sie lässt sich als Update über die alte installieren.

## Funktionen (Schritt 1)

- QWERTZ-Layout (pro Sprache auf QWERTY umschaltbar)
- Nach oben wischen: Zahlen und Zeichen auf den oberen beiden Reihen
- Nach unten wischen: Zeichen auf der unteren Buchstabenreihe
- Lange drücken: Umlaute und Akzente
- Leertaste seitlich wischen: Sprache wechseln (Deutsch, English, Nederlands)
- Emoticon-Taste (^.^, :D, ¯\_(ツ)_/¯ …)
- Zwischenablage-Knopf links oder rechts in der Leiste
- Automatische Großschreibung, doppeltes Leerzeichen → Punkt
